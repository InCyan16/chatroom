# Chatroom

一个给小圈子（20 人以内）用的私密群聊网站，手机和电脑都能用。

本项目复制自同学的 [ZihaoFU245/CommonRoom](https://github.com/ZihaoFU245/CommonRoom)（Rust + Axum 后端、Preact 前端、SQLite 存储，编译成一个内嵌前端的单文件程序），在它的基础上改成下面描述的样子。遵循原项目的 GPL-3.0 许可证。

> 状态：刚从 CommonRoom 复制过来，代码目前还是 CommonRoom 的原样，下面的功能正在改造中。原项目的技术文档（编译、部署、配置）见 [docs/COMMONROOM.md](docs/COMMONROOM.md)，在改造完成前仍然适用。

## 使用流程

1. **输入通行密码**：第一次访问网站时需要输入大家共用的通行密码。
2. **创建账号**：填写名字（不能和别人重名），头像可以上传，也可以不传（不传就用名字首字自动生成），还可以选择设置一个 PIN 码。不需要邮箱。
3. **进入聊天室**：同一台设备以后再访问，会直接进入聊天室。

换新设备时，输入自己的名字就能登录；如果设置了 PIN，还要输入 PIN。

## 功能

- 只有一个大群，所有成员都在里面
- 发送文字和图片（一次最多 9 张，支持 GIF，图片自动压缩）
- 引用别人的消息回复
- 随时撤回自己的消息，撤回后不留痕迹
- @ 某人，被 @ 的消息会高亮
- 表情回应
- 在线状态、群成员列表
- 修改名字和头像、退出登录、多设备同时登录、注销账号

### 消息保留规则

消息发出后 24 小时内，如果某个人没有真正滚动看到这条消息，它就会对这个人永久消失；看过的人会一直保留。因此新成员只能看到最近 24 小时内的消息。

### 管理员

- **站长**：网站主人，永远是管理员，不能被撤销。只有站长可以任命或撤销其他管理员。站长账号必须设置 PIN。
- **管理员**（包括站长）：
  - 可以置顶 1 条消息，置顶一周后自动消失
  - 可以禁言成员 24 小时，也可以提前解除；管理员不能被禁言
- 被禁言的人仍然可以查看消息、点表情回应、撤回自己的消息、修改名字和头像

## 界面

深色主题，风格类似 ChatGPT 群聊，界面为简体中文，适配电脑横屏和手机竖屏。

## 部署

和 CommonRoom 部署在同一台服务器上，作为独立的第二个程序运行，挂在子路径 `/chatroom/` 下，数据与 CommonRoom 互不相通。访问链路为 Cloudflare → Nginx → 本程序（只监听本机端口）。服务器上不需要安装 Node.js。

通行密码等敏感配置不会提交到仓库。
